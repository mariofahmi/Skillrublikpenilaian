Rubrik Analitik 4 Pita Mutu

Menghasilkan indikator penilaian operasional yang terukur untuk: Sangat Baik (85-100), Baik (75-84), Cukup (60-74), dan Kurang (<60) menggunakan Kata Kerja Operasional (KKO) Taksonomi Bloom (C1-C6).

Konversi 7 Huruf Mutu UNIROW

Dilengkapi tabel pedoman nilai akhir resmi kampus (A, B+, B, C+, C, D, E) lengkap dengan bobot nilai, rentang angka, serta predikat kelulusan mahasiswa.

Validasi Bobot 100% Otomatis

Menjamin penjumlahan bobot asesmen (Partisipasi, Tugas, Kuis, UTS, UAS, Proyek) selalu bernilai tepat 100%. Dilengkapi algoritma normalisasi apabila tabel RPS asli memiliki ketidakseimbangan proporsi.

Cara Penggunaan

Instalasi ke Antigravity / Cursor / IDE

Gunakan skill ini dalam hitungan detik di workspace coding atau antarmuka asisten AI Anda.

Clone skill langsung ke direktori skills workspace Antigravity Anda:

git clone https://github.com/mariofahmi/Skillrublikpenilaian.git .agents/skills/rubrik-penilaian-unirow

Panggil langsung di antarmuka chat Antigravity IDE:

/rubrik-penilaian-unirow @RPS_Mata_Kuliah.docx

Jalankan via terminal Python bawaan:

py .agents/skills/rubrik-penilaian-unirow/scripts/build_rubrik.py "RPS.docx" -o "Output_Rubrik"
Teks berhasil disalin ke clipboard!
